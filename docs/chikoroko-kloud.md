# ChikoRoko × GRGY — Kloud

The bilingual project uses the artist's archive at
`D:\1. Art\2022\Collab\Chiko Roko Collab`.

- `CRGRGY promo.png` (1024 × 1024): original collaboration promotional graphic,
  used as the project cover and Projects listing preview.
- `roko grgy model-01.png` (2964 × 2964): original design sheet.
- `Снимок экрана 2026-10-23 193716.png` (1706 × 1015): archived R.Toys profile
  showing the released Kloud toy, kept as documentation with browser context.

All three originals retain their filenames and bytes under
`images/projects/originals/chikoroko-kloud/`. Image dimensions were measured with
Sharp. Stable derivative indices are 0, 1, and 2 respectively. Responsive WebP
derivatives preserve proportions; the promo and design sheet use lossless WebP.

The earlier draft depended on a remote toy render. Direct CDN requests and the
R.Toys image endpoint returned HTTP 403 during this update. That render is not
claimed to have been downloaded or verified. The approved archive supplies actual
media instead, and the shared renderer uses the existing local-media schema.

EN/RU descriptions and the three links from the draft are preserved. The local
`Descripion GRGY x ROKO.txt` supplies the collaboration concept, R.Toys artist
profile and Sketchfab archive link. The current official toy-page HTML was
retrieved, but the external images were blocked. No sales, edition count or
additional production credits are inferred.
