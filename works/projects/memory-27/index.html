Memory #27

Year
2022
Project Type
Collaborative Digital Artwork
Medium
Digital Art / 2D Graphics / 3D Animation
Artists
Tim Baym, GRGY (Grgy Sukhanov)

Memory #27 is a collaborative digital artwork created by Tim Baym and GRGY in 2022.

The project places Kloud within a dark three-dimensional scene featuring a burning car, smoke, and a human figure. GRGY's recognizable graphic language contrasts with the realistic environment, bringing a cartoon-like character into an unexpected setting.

Combining 2D graphics and 3D animation, Memory #27 was featured in a December 2022 interview with Tim Baym published by Sobaka.ru.
