# Archived commerce implementation

The original store, cart, product pages, browser scripts, Supabase Edge Function
and SQL schema are preserved here unchanged. GitHub Pages excludes this directory
through `_config.yml`; the development server also blocks archive requests.

Old public HTML URLs redirect to Works and are excluded from the sitemap.
No Supabase data was altered, no orders were submitted, and no cart storage was cleared.
Restoring this code is a separate task: its relative paths assume the original
repository-root layout. `styles.css` retains the original commerce styles.
